# openftgs-xr

An Apache-2.0 Python package that implements a VR/desktop player for openftgs models generated by [openftgs](https://github.com/samaust/openftgs).

## Status

Early planning: there is no code yet, so nothing can be installed or run. The specification, `docs/spec/openftgs-xr-spec.md`, is a skeleton being written; the milestones of `docs/prd/milestones.md` will follow from it, and the implementation from them.

## Relation to openftgs

openftgs trains the models; openftgs-xr only loads and displays them. `docs/spec/openftgs-spec.md` is a copy of the openftgs spec, kept as the reference for the files openftgs-xr reads. The openftgs-xr spec, `docs/spec/openftgs-xr-spec.md`, is this package's own.

## Repository layout

- `docs/spec/`: the openftgs-xr spec, the copy of the openftgs spec, and the record of spec revisions.
- `docs/prd/`: the milestones, the implementation questions and their provisional decisions, and the source log.
- `docs/GLOSSARY.md`: the project's vocabulary.
- `docs/agents/`: how the agent skills use the issue tracker, its labels, the guidelines and the domain docs.
- `.claude/skills/`: the agent workflow, from planning to implementation and review.
