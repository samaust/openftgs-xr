# Milestones

The bottom-up build of openftgs-xr from its spec (`docs/spec/openftgs-xr-spec.md`, revision 2), one milestone per PRD, in the order of the spec's §2.1 bands. The order is a suggestion, not part of the spec (CLAUDE.md); the spec items and tests are the spec's. A milestone is done when every test it lists passes on the reference hardware (§1.1), except where a lane is unavailable, which the implement skills record ("Unverified tickets" in `docs/agents/issue-tracker.md`).
